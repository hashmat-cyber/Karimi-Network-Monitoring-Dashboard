# Karimi Network Monitoring Dashboard

A beginner-friendly Flask dashboard for monitoring network devices, checking reachability, tracking status, and recording alerts.

## Features
- Device management
- Reachability checks
- Online/Offline status
- Alerts
- Dashboard overview
- SQLite database

## Run
```bash
python -m venv venv
# Windows: .\\venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
